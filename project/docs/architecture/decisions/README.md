# Decisions

No project decisions are recorded by this template. Create an ADR from the [template](../../_templates/adr.md) only for a durable choice whose rationale would otherwise be lost. Use a stable ID, scope, date and status. For a genuinely unknown historical date use `unknown` and explain the source; do not invent the original date.

Keep superseded decisions for history. Set `supersedes` / `superseded_by` to the actual related ADR ID and link the new decision. Record a meaningful reconsideration trigger. Accepted compromises belong in [debt](../../debt/README.md), with a link to the decision when relevant.

Use `decision_status` for the record workflow state; `status` is reserved for OKF document lifecycle (`draft`, `stable`, `deprecated`).
