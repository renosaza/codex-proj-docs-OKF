# Local setup

Template — not an executable procedure yet.

1. Record supported OS/runtime versions from actual manifests and CI; identify the package manager and lockfile.
2. Add the real dependency installation command and link the existing environment-variable example. Explain how required credentials are obtained without storing them here.
3. Add the actual run command, service dependencies and local URL or CLI invocation.
4. Add the smallest working verification command and its observable success criterion. State which checks have actually run and on which revision.

Keep one supported path first. Do not invent containers, Make targets or prerequisites that the repository does not use.
