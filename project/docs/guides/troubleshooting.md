# Troubleshooting

Template — add only reproduced incidents or verified diagnostic paths.

For each useful entry record: symptom, environment/version, first read-only check, evidence that distinguishes possible causes, confirmed fix, and a verification step. Mark unresolved hypotheses as unverified. Include a rollback step when the fix changes persistent state.

Link actual log locations and commands after verifying them; omit secrets and unnecessary raw logs. A concise confirmed failed approach is worth preserving when its conditions prevent repeated investigation.
